# Library Management System

A console-based Library Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

## Project Overview

This project is designed to manage books and users in a library. It allows users to add books, register users, display library records, borrow books, and return books through a simple menu-driven interface.

## Features

* Add new books
* Register library users
* Display all available books
* Display registered users
* Borrow books
* Return books
* Track book availability
* Track books borrowed by users
* Menu-driven console interface

## OOP Concepts Used

* Classes and Objects
* Encapsulation
* Constructors
* Private and Public Access Specifiers
* Composition
* Member Functions
* Vectors for Data Management

## Technologies Used

* C++
* Standard Template Library (STL)
* `iostream`
* `vector`
* `string`

## Project Structure

`LibraryManagementSystem.cpp` — Contains the complete implementation of the Library Management System.

## How to Run

1. Download or clone the repository.
2. Open the `.cpp` file in a C++ compatible IDE or compiler.
3. Compile the program.
4. Run the executable.
5. Use the menu options to interact with the system.

## Academic Context

This project was developed as part of university coursework to practice and demonstrate fundamental Object-Oriented Programming concepts in C++.
